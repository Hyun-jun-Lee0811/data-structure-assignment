## 과제
트리를 괄호 표기법(예: `A(B(E,F),C,D(G))`)으로 입력받아, 트리 자료구조를 별도로 구성하지 않고 문자열을 한 번 스캔하면서 전체 노드 수, 단말/비단말 노드 수, 트리의 높이와 차수, 특정 노드의 부모/자식, 계층적 트리 출력까지 계산하는 프로그램을 구현하였다.

### 문자열 스캔 기반 파싱 구현
포인터로 연결된 트리 구조체를 만드는 대신, 입력 문자열을 왼쪽에서 오른쪽으로 한 번 스캔하면서 상태(state)로 현재 어떤 토큰이 와야 하는지를 판단하도록 구현하였다.

```c
int state; // 0: 노드가 와야함, 1: 노드 방금 읽음, 2: 괄호 방금 닫음
```

문자 하나를 읽을 때마다 state 값에 따라 처리 방식을 분기하였다.

---

### 노드 스택을 이용한 부모 추적
괄호를 열 때(`(`) 직전에 읽은 노드를 스택에 push하고, 괄호를 닫을 때(`)`) pop하는 방식으로 현재 노드의 부모를 스택의 top에서 바로 찾을 수 있도록 구현하였다.

```c
char p = stack1[top - 1];
parent[c - 'A'] = p;
```

---

### 카운터 스택을 이용한 차수 계산
각 조상 노드가 지금까지 몇 개의 자식을 만들었는지를 `stack1`과 같은 크기의 `stack2`에 누적시켜, 괄호가 닫히는 시점에 그 노드의 차수(자식 수)가 확정되도록 구현하였다.

```c
child[p - 'A'][childNum[p - 'A']] = c;
childNum[p - 'A']++;
stack2[top - 1]++;
```

전체 노드를 한 번 더 순회하며 `childNum` 값들 중 최댓값을 구해 트리의 차수로 사용하였다.

```c
if (childNum[i] > degree)
    degree = childNum[i];
```

### 노드 C의 부모/자식 조회
스캔이 끝난 후에는 각 노드의 부모(`parent[]`)와 자식 목록(`child[][]`)이 이미 배열에 저장되어 있으므로, 이를 그대로 조회하여 출력하도록 구현하였다.

```c
printf("%c의 부모 : %c\n", TARGET, parent[TARGET - 'A']);
```

---

### 입력 문법 오류 처리
대문자가 아닌 문자, 중복된 노드 이름, 괄호 짝이 맞지 않는 경우, 콤마나 괄호의 위치가 잘못된 경우 등을 각 state 분기에서 검사하여 잘못된 입력 시 오류 메시지를 출력하고 프로그램을 종료하도록 구현하였다.

```c
void error(char* msg)
{
    printf("오류: %s\n", msg);
    exit(1);
}
```

### 트리 계층 구조 출력 기능
재귀 함수 `printTree()`를 이용하여 트리를 왼쪽으로 눕힌 형태로 출력하도록 구현하였다. 이전 깊이까지의 들여쓰기 문자열(`prefix`)을 인자로 전달하여, 각 노드가 자신의 깊이만큼 `+---`를 반복 출력하도록 하였다.

```c
if (isRoot)
    printf("%c\n", node);
else
    printf("%s+---%c\n", prefix, node);
```

자식 노드를 출력할 때는 현재까지의 prefix에 공백 4칸을 추가하여 다음 깊이로 넘겨주었다.

```c
strcpy(newPrefix, prefix);
strcat(newPrefix, "    ");
```
