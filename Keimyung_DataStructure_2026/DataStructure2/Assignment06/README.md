이후 동일한 50개의 탐색 대상에 대해 순차 탐색, BST 탐색, AVL 트리를 수행하여 각각의 비교 횟수를 측정하고, 세 자료구조의 생성 비용과 탐색 성능을 비교·분석한다.

## 1. 실제 저장된 서로 다른 값의 수

100개의 정수를 생성한 결과, 중복된 값이 포함되었다.

중복된 값은 다음과 같다.

* 213
* 518
* 838
* 747
* 202

따라서 실제로 저장된 서로 다른 값의 수는 다음과 같다.

**95개**

즉, 100개의 입력값 중 5개가 중복되어 배열, BST, AVL에는 각각 **95개의 서로 다른 값**이 저장되었다.

## 2. 생성 과정의 비교 횟수

| 자료구조 | 비교 횟수 |
| ---- | ----: |
| 배열   | 4,558 |
| BST  |   601 |
| AVL  |   519 |

배열은 새로운 값이 기존 배열에 존재하는지 확인하기 위해 저장된 값들을 순차적으로 비교해야 하기 때문에 비교 횟수가 가장 많았다.

반면 BST는 각 노드의 값과 비교한 뒤 값의 크기에 따라 왼쪽 또는 오른쪽 서브트리 중 하나만 탐색하므로 배열보다 훨씬 적은 비교 횟수로 삽입할 수 있었다.

AVL은 BST의 구조를 유지하면서 삽입 후 균형을 맞추기 때문에 이번 실험에서는 BST보다 더 적은 **519회**의 비교가 발생하였다.

## 3. 자료구조의 크기와 높이

| 자료구조 | 크기 | 높이 |
| ---- | -: | -: |
| 배열   | 95 |  - |
| BST  | 95 | 13 |
| AVL  | 95 |  8 |

배열에는 서로 다른 값 95개가 저장되었으며, 트리 역시 중복 값을 저장하지 않으므로 BST와 AVL 모두 95개의 노드를 가진다.

그러나 BST와 AVL은 트리의 구조에서 차이가 발생하였다.

* BST 높이: **13**
* AVL 높이: **8**

AVL은 삽입 과정에서 각 노드의 균형을 확인하고 필요한 경우 회전을 수행하여 트리의 높이가 지나치게 커지는 것을 방지한다.

반면 일반 BST는 삽입 순서에 따라 트리의 형태가 달라지며 별도의 균형 조정을 하지 않는다. 따라서 이번 실험에서는 BST가 AVL보다 더 높은 **13**의 높이를 가지게 되었다.

50개의 탐색 대상 중 실제 저장된 값을 찾은 경우는 4개였으며, 나머지 46개는 존재하지 않는 값이었다.

반면 BST와 AVL은 현재 노드의 값과 비교한 뒤 탐색할 방향을 결정하기 때문에 전체 데이터를 모두 확인하지 않고도 탐색을 종료할 수 있었다.

## 5. BST와 AVL의 높이가 다른 이유

BST와 AVL은 모두 이진 탐색 트리의 구조를 사용하지만, 트리의 균형을 유지하는 방식에서 차이가 있다.

일반 BST는 새로운 값이 삽입되는 순서에 따라 트리의 높이가 결정된다. 특정 방향으로 값이 계속 삽입되면 한쪽 서브트리가 길어질 수 있으며, 이 경우 트리의 높이가 증가한다.

반면 AVL 트리는 삽입할 때마다 각 노드의 균형 상태를 확인하고, 균형이 깨진 경우 좌회전이나 우회전 등의 회전을 수행한다. 이를 통해 한쪽으로 지나치게 치우친 구조가 만들어지는 것을 방지한다.

이번 실험에서는 다음과 같은 결과가 나타났다.

```text
BST : 높이 13
AVL : 높이 8
```

따라서 동일하게 95개의 데이터를 저장했음에도 AVL이 BST보다 **5단계 낮은 트리**를 만들었다.

---

## 6. 트리의 높이가 탐색 비교 횟수에 미치는 영향

이진 탐색 트리에서는 현재 노드의 값과 비교한 후 왼쪽 또는 오른쪽 서브트리 중 하나만 계속 탐색한다.

따라서 트리의 높이가 낮을수록 탐색 과정에서 방문해야 하는 노드의 수가 줄어들 가능성이 높아지고, 결과적으로 비교 횟수도 감소한다.

이번 실험에서도 이러한 차이가 확인되었다.

| 자료구조 | 높이 | 평균 탐색 비교 |
| ---- | -: | -------: |
| BST  | 13 |     8.30 |
| AVL  |  8 |     6.68 |

BST는 높이가 13인 반면 AVL은 높이가 8로 더 낮았다. 실제 탐색에서도 AVL의 평균 비교 횟수는 **6.68회**로 BST의 **8.30회**보다 적었다.

즉, 이번 실험에서는 AVL이 트리의 높이를 낮게 유지한 것이 실제 탐색 과정에서 비교 횟수를 줄이는 데 영향을 주었다.

특히 AVL의 높이는 BST보다 5만큼 낮았으며, 평균 탐색 비교 횟수도 **1.62회 감소**하였다.

## 7. 생성 비용과 탐색 비용 비교

세 자료구조는 데이터를 저장하는 과정과 저장된 데이터를 탐색하는 과정에서 서로 다른 특징을 보였다.

### 생성 비용

```text
배열 : 4,558회
BST  :   601회
AVL  :   519회
```

배열은 새로운 값이 중복인지 확인하기 위해 기존 원소들을 순차적으로 비교해야 하기 때문에 생성 과정에서 가장 많은 비교가 발생하였다.

BST는 값의 크기를 이용하여 탐색 범위를 줄이면서 삽입하기 때문에 배열보다 훨씬 적은 비교 횟수가 필요했다.

AVL은 BST와 유사하게 값을 비교하면서 삽입하지만, 균형을 유지하기 때문에 이번 실험에서는 **519회**의 비교로 가장 적은 생성 비교 횟수를 기록하였다.

### 탐색 비용

```text
순차 탐색 : 4,513회
BST       :   415회
AVL       :   334회
```

탐색에서도 배열의 순차 탐색이 가장 많은 비교를 수행하였다.

50개의 탐색에 대해 평균적으로 배열은 **90.26회**의 비교가 필요했지만, BST는 **8.30회**, AVL은 **6.68회**만 필요했다.

이번 실험에서 평균 비교 횟수를 비교하면 다음과 같다.

* 순차 탐색 → BST: 평균 **81.96회 감소**
* 순차 탐색 → AVL: 평균 **83.58회 감소**
* BST → AVL: 평균 **1.62회 감소**

따라서 트리에 데이터를 저장할 때 추가적인 구조를 사용하는 대신, 이후 반복적으로 데이터를 탐색하는 상황에서는 트리 구조를 사용하는 것이 탐색 비교 횟수를 크게 줄일 수 있음을 확인할 수 있었다.

## 8. 전체 비교 횟수 분석

생성 과정과 50회의 탐색을 모두 포함하여 비교하면 다음과 같다.

| 자료구조 | 생성 비교 | 탐색 비교 |     전체 비교 |
| ---- | ----: | ----: | --------: |
| 배열   | 4,558 | 4,513 | **9,071** |
| BST  |   601 |   415 | **1,016** |
| AVL  |   519 |   334 |   **853** |

전체 비교 횟수에서도 배열이 **9,071회**로 가장 많았으며, BST는 **1,016회**, AVL은 **853회**로 나타났다.

이번 실험에서는 AVL이 생성 과정과 탐색 과정 모두에서 BST보다 적은 비교 횟수를 기록하였다.

특히 AVL은 트리의 높이를 8로 유지하여 BST의 높이 13보다 낮은 구조를 만들었고, 이 차이가 탐색 과정에서 평균 비교 횟수가 **8.30회에서 6.68회로 감소**하는 결과와 함께 나타났다.

## 9. 시간 복잡도 관점

일반적인 시간 복잡도를 비교하면 다음과 같다.

| 자료구조      | 탐색                   | 삽입/생성                |
| --------- | -------------------- | -------------------- |
| 배열의 순차 탐색 | O(n)                 | O(n)                 |
| BST       | 평균 O(log n), 최악 O(n) | 평균 O(log n), 최악 O(n) |
| AVL       | O(log n)             | O(log n)             |

배열의 순차 탐색은 저장된 데이터의 순서에 따라 처음부터 하나씩 확인하기 때문에 데이터의 수가 증가할수록 탐색 비용도 증가한다.

BST는 균형이 잘 유지되는 경우 탐색 범위를 계속 줄일 수 있지만, 삽입 순서에 따라 트리가 한쪽으로 치우치면 최악의 경우 선형적인 구조가 될 수 있다.

AVL은 삽입 과정에서 트리의 균형을 유지하기 때문에 탐색과 삽입 모두 높이에 비례하는 효율적인 구조를 유지할 수 있다.

## 10. 결론

이번 실험에서는 동일한 100개의 입력값을 배열, BST, AVL에 저장하고 생성 및 탐색 과정에서 발생하는 비교 횟수를 측정하였다.

실험 결과 실제 저장된 서로 다른 값은 **95개**였으며, 생성 과정의 비교 횟수는 배열 **4,558회**, BST **601회**, AVL **519회**로 나타났다.

탐색에서는 순차 탐색이 총 **4,513회**, BST가 **415회**, AVL이 **334회**의 비교를 수행하였다. 평균 비교 횟수 역시 순차 탐색 **90.26회**, BST **8.30회**, AVL **6.68회**로 큰 차이가 나타났다.

특히 BST의 높이는 **13**, AVL의 높이는 **8**로 AVL이 더 낮은 높이를 유지하였다. AVL은 삽입 과정에서 균형이 깨질 경우 회전을 수행하여 트리의 높이가 한쪽으로 지나치게 증가하지 않도록 하기 때문이다.

이번 실험 결과를 통해 단순히 데이터의 개수가 같더라도 **자료구조의 내부 구조와 트리의 높이에 따라 실제 탐색에 필요한 비교 횟수가 달라질 수 있음**을 확인할 수 있었다.

또한 생성 과정과 50회의 탐색을 합산했을 때 배열은 **9,071회**, BST는 **1,016회**, AVL은 **853회**의 비교가 발생하였다. 따라서 이번 실험에서는 트리 구조를 이용하는 BST와 AVL이 배열의 순차 탐색보다 훨씬 적은 비교로 데이터를 처리할 수 있었으며, 특히 AVL은 균형을 유지함으로써 BST보다 낮은 높이와 적은 탐색 비교 횟수를 보였다.
