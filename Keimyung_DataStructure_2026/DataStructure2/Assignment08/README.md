## 과제

최소 비용 신장 트리를 구하는 Kruskal 알고리즘과 Prim 알고리즘을 구현하고, 그래프의 표현 방식과 밀도에 따른 성능을 비교한다.

- **Kruskal 알고리즘**: 인접 리스트(Adjacency List)를 이용하여 최소 비용 신장 트리 구성
- **Prim 알고리즘**: 인접 행렬(Adjacency Matrix)을 이용하여 최소 비용 신장 트리 구성
- 희소 그래프(Sparse Graph)와 밀집 그래프(Dense Graph)를 각각 생성하여 비교
- MST 간선 수, 총 비용, 메모리 사용량, 실행 시간 측정

## 구현 내용

### 1. 그래프 생성

- 정점 수: 50개
- 희소 그래프: 간선 100개
- 밀집 그래프: 간선 600개
- 간선 가중치: 1~100 범위
- 무방향 가중치 그래프 생성
- 중복 간선과 자기 자신을 연결하는 간선 제외
- 연결 그래프가 되도록 먼저 신장 트리를 구성한 후 추가 간선 생성

### 2. Kruskal 알고리즘 - 인접 리스트

- 인접 리스트를 이용하여 그래프 표현
- 간선을 가중치 오름차순으로 정렬
- Union-Find 자료구조를 사용하여 사이클 발생 여부 확인
- 사이클이 발생하지 않는 간선을 선택하여 MST 구성
- 경로 압축과 Union by Rank를 적용하여 Union-Find 연산 최적화

### 3. Prim 알고리즘 - 인접 행렬

- 인접 행렬을 이용하여 그래프 표현
- 시작 정점에서 출발하여 MST에 연결된 정점 집합 확장
- 현재 MST와 연결되는 간선 중 최소 가중치 간선 선택
- `key`, `parent`, `visited` 배열을 이용하여 MST 구성
- 인접 행렬을 순회하는 방식으로 최소 가중치 정점 탐색

### 4. 성능 측정

각 알고리즘 실행 결과에서 다음 항목을 측정한다.

- 정점 수와 간선 수
- MST 간선 수와 총 가중치
- 메모리 사용량
- 실행 시간

## 결과 분석

### 1. 희소 그래프와 밀집 그래프 비교

Kruskal 알고리즘은 희소 그래프에서 0.032800ms, 밀집 그래프에서 0.104600ms가 측정되었다. 간선 수가 100개에서 600개로 증가하면서 실행 시간도 증가하였다.

Prim 알고리즘은 희소 그래프에서 0.018800ms, 밀집 그래프에서 0.031900ms가 측정되었다. 이번 실행 결과에서는 간선 수가 증가해도 Kruskal보다 실행 시간 증가 폭이 작았다.

### 2. 인접 리스트와 인접 행렬의 메모리 사용량 비교

인접 리스트를 사용하는 Kruskal 알고리즘은 희소 그래프에서 5,788 Bytes, 밀집 그래프에서 27,788 Bytes를 사용하였다. 간선 수가 증가하면 저장해야 하는 인접 리스트 노드도 증가하므로 메모리 사용량이 커진다.

인접 행렬을 사용하는 Prim 알고리즘은 두 그래프 모두 11,188 Bytes로 측정되었다. 정점 수가 동일하기 때문에 인접 행렬의 크기도 동일하며, 간선 수가 증가해도 행렬의 크기는 변하지 않는다.

따라서 희소 그래프에서는 인접 리스트가 메모리 측면에서 유리했고, 밀집 그래프에서는 이번 측정 기준으로 인접 행렬이 더 적은 메모리를 사용했다.

### 3. Kruskal 알고리즘과 Prim 알고리즘 비교

Kruskal 알고리즘은 간선을 가중치 순서로 정렬한 뒤 Union-Find를 이용하여 사이클이 발생하지 않는 간선을 선택한다. 일반적인 시간 복잡도는 \(O(E \log E)\)이다.

Prim 알고리즘은 현재 MST에 연결된 정점 집합을 확장하면서 최소 가중치 간선을 선택한다. 이번 구현처럼 인접 행렬을 순회하여 다음 정점을 선택하는 방식의 시간 복잡도는 \(O(V^2)\)이다.

측정 결과에서는 Prim 알고리즘이 두 그래프 모두 더 짧은 실행 시간을 보였다. 다만 실행 시간은 그래프 크기와 구현 방식, 실행 환경의 영향을 받으므로 이 결과만으로 모든 상황에서 Prim 알고리즘이 더 빠르다고 단정할 수는 없다.

### 4. MST 결과 검증

- 정점이 50개인 연결 그래프의 MST 간선 수는 \(V-1=49\)개이다.
- 네 가지 테스트 모두 MST 간선 수가 49개로 출력되었다.
- 동일한 희소 그래프를 사용한 Kruskal과 Prim의 MST 비용은 모두 1158이다.
- 동일한 밀집 그래프를 사용한 Kruskal과 Prim의 MST 비용은 모두 246이다.

따라서 두 알고리즘이 동일한 그래프에 대해 같은 MST 비용을 산출했음을 확인할 수 있다.

## 결론

이번 과제에서는 Kruskal 알고리즘과 Prim 알고리즘을 구현하고, 희소 그래프와 밀집 그래프에서 메모리 사용량과 실행 시간을 비교하였다.

Kruskal 알고리즘은 인접 리스트를 사용하기 때문에 희소 그래프에서 메모리 사용량이 적었지만, 간선 수가 증가하면서 메모리 사용량과 실행 시간이 증가하였다. 반면 Prim 알고리즘은 인접 행렬의 크기가 정점 수에 의해 결정되므로 두 그래프에서 메모리 사용량이 동일하게 측정되었다.

또한 네 가지 테스트 모두 MST 간선 수가 49개였으며, 동일한 그래프에 대한 두 알고리즘의 MST 비용도 일치하였다. 이를 통해 그래프 표현 방식과 알고리즘의 특성이 메모리 사용량 및 실행 시간에 영향을 준다는 점을 확인하였다.
