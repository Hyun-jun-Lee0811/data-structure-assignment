## 과제

정점 10개와 간선 20개로 구성된 가중치 무방향 그래프(Weighted Undirected Graph)를 무작위로 생성하고, 모든 서로 다른 정점 쌍에 대한 최단경로(Shortest Path)와 최단거리(Shortest Distance)를 계산한다.

- 정점(Vertex) 수: 10개
- 간선(Edge) 수: 20개
- 정점 번호: 0~9
- 간선 가중치: 1~100 사이의 양의 정수
- 최단경로 알고리즘: Floyd-Warshall Algorithm
- 최단경로에 포함되는 정점의 순서와 최단거리 출력
- 중복을 제외한 모든 정점 쌍 45개에 대한 결과 출력

## 구현 내용

### 1. 그래프 생성

- 정점 10개와 간선 20개를 갖는 무방향 가중치 그래프 생성
- 각 간선에 1~100 사이의 무작위 가중치 부여
- 자기 자신을 연결하는 간선(Self-loop) 제외
- 동일한 두 정점 사이의 중복 간선 방지
- 먼저 9개의 간선을 생성하여 모든 정점을 연결한 후, 추가 간선을 생성하여 총 20개의 간선 구성
- 인접 행렬(Adjacency Matrix)을 이용하여 간선과 가중치 저장

### 2. Floyd-Warshall 알고리즘

- 모든 정점 쌍 사이의 최단거리를 계산하는 알고리즘
- 중간 정점 `k`를 거쳐 가는 경로와 기존 경로의 거리를 비교
- 중간 정점을 거쳐 가는 경로가 더 짧으면 최단거리 갱신
- 최단거리뿐 아니라 경로 복원을 위한 다음 정점 정보도 함께 갱신

### 3. 최단경로 복원

- `dist[i][j]`: 정점 `i`에서 정점 `j`까지의 최단거리 저장
- `next[i][j]`: 정점 `i`에서 정점 `j`로 이동할 때 다음에 방문할 정점 저장
- 최단거리가 갱신될 때 `next[i][j]`도 함께 갱신
- `printPath()` 함수를 이용하여 실제 최단경로에 포함되는 정점 순서 출력

### 4. 모든 정점 쌍 출력

- 정점 번호가 0부터 9까지인 그래프의 모든 서로 다른 정점 쌍 계산
- `i < j` 조건을 이용하여 중복되는 정점 쌍 제외
- 총 45개 정점 쌍에 대한 출발 정점, 도착 정점, 최단경로, 최단거리 출력
- 마지막에 전체 정점 쌍의 개수 출력

## 결과 분석

### 1. 그래프 생성 결과

실행 결과에서 정점 10개와 간선 20개가 생성된 것을 확인하였다. 간선 가중치는 모두 1~100 범위에 있으며, 생성된 간선 목록에는 자기 루프와 중복 간선이 나타나지 않았다.

또한 정점들을 연결하는 간선이 존재하므로 모든 정점 쌍에 대해 최단경로를 계산할 수 있었다.

### 2. 최단거리 계산 결과

Floyd-Warshall 알고리즘을 이용하여 모든 정점 쌍의 최단거리를 계산하였다. 직접 연결된 간선만 고려하는 것이 아니라, 여러 정점을 거쳐 이동하는 경로의 가중치 합도 비교하여 더 짧은 경로를 선택하였다.

예를 들어 정점 0에서 정점 2까지는 직접 연결된 간선이 없지만, 다음 경로를 통해 이동할 수 있다.

- 최단경로: 0 → 6 → 2
- 간선 가중치: 47 + 14
- 최단거리: 61

또한 정점 1에서 정점 4까지는 직접 연결된 간선의 가중치가 36이지만, 정점 7을 거치는 경로의 가중치 합이 더 작다.

- 최단경로: 1 → 7 → 4
- 간선 가중치: 10 + 1
- 최단거리: 11

이를 통해 간선 수가 적거나 직접 연결되어 있다는 사실만으로 최단경로가 결정되는 것이 아니라, 경로에 포함된 모든 간선 가중치의 합을 기준으로 최단경로가 결정됨을 확인하였다.

### 3. 최단경로 복원 결과

`next` 배열을 이용하여 최단거리뿐 아니라 실제 경로에 포함되는 정점의 순서도 출력하였다. 예를 들어 정점 1에서 정점 3까지의 최단경로는 다음과 같다.

- 최단경로: 1 → 7 → 4 → 9 → 3
- 간선 가중치: 10 + 1 + 9 + 10
- 최단거리: 30

이처럼 경로 복원 결과에 포함된 간선들의 가중치 합이 출력된 최단거리와 일치하는 것을 확인할 수 있다.

### 4. 모든 정점 쌍 출력 결과

정점 10개에서 서로 다른 두 정점을 선택하는 경우의 수는 다음과 같다.

\[
\binom{10}{2}=\frac{10(10-1)}{2}=45
\]

중첩 반복문에서 `i < j` 조건을 적용하여 정점 쌍을 중복 없이 출력하였다. 실행 결과 마지막에 `Total vertex pairs : 45`가 출력되어 모든 정점 쌍을 처리했음을 확인하였다.

### 5. 시간 및 공간 복잡도

| 항목 | 복잡도 |
|---|---|
| Floyd-Warshall 시간 복잡도 | \(O(V^3)\) |
| 거리 배열 공간 복잡도 | \(O(V^2)\) |
| 다음 정점 배열 공간 복잡도 | \(O(V^2)\) |

Floyd-Warshall 알고리즘은 세 개의 반복문을 통해 중간 정점을 고려하므로 시간 복잡도는 \(O(V^3)\)이다. 거리 배열과 다음 정점 배열은 각각 \(V \times V\) 크기이므로 공간 복잡도는 \(O(V^2)\)이다.
